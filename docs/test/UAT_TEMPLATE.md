# PyCC2 用户验收测试（UAT）模板

- 版本：1.0
- 日期：2026-11-07
- 适用阶段：每个 Phase 结束前，发布候选版本（RC）必须执行
- 负责人：product-manager（组织）、tester（执行）、solo-coder（修复）

## 1. 使用说明

1. 复制本文件，命名为 `UAT_<版本号>_<日期>.md`。
2. 按顺序执行每个用例。不要跳过用例。
3. 每个用例填写“结果”和“证据”。
4. 结果为“失败”时，必须提交缺陷单，并填写缺陷 ID。
5. 全部用例通过后，由 product-manager 签字。

结果取值：`通过` / `失败` / `阻塞` / `不适用`。
