# User Journey Test Enhancements Summary (v0.9.1)

## Context

Based on context analysis, we identified 4 user journey test gaps (P1-P2 priority):

1. **P1**: Cross-session continuity (save→exit→restart→load) — true process restart
2. **P1**: First-time install in Docker clean environment
3. **P2**: Advanced command integration (command queue + guard + bridge together)
4. **P2**: Error recovery journey (error→save→load) — full recovery workflow

4. **Error recovery**: No **full error→save→load→continue** workflow

## Solution Delivered

### New Test File: `tests/e2e/test_journey_enhancements_e2e.py`

Created comprehensive test suite with 4 test classes:

#### 1. `TestCrossSessionContinuityE2E`

**Test**: `test_cross_session_save_exit_restart_load`

- Uses **subprocess** to simulate true process restart
- Phase 1: Start game → run ticks → save → record unit state
- Phase 2: New process → load save → verify exact state match
- Validates: unit positions, HP, ammo, morale all restored

**TC Coverage**: TC-037 (Cross-session continuity)

#### 2. `TestDockerCleanInstallE2E`

**Test**: `test_docker_clean_environment_startup`

- Builds Docker image from Dockerfile
- Runs container with **no mounted volumes** (pristine environment)
- Verifies all subsystems initialize (renderer, AI, event bus, sound)
- Runs 10 ticks to confirm game loop stability

**TC Coverage**: TC-038 (Docker clean install)

**Skip condition**: `SKIP_DOCKER_TESTS=1` (for CI environments without Docker)

#### 3. `TestAdvancedCommandIntegrationE2E`

**Test**: `test_command_queue_plus_garrison_plus_bridge`

- Integrates 3 advanced commands in one scenario:
  1. Infantry queues 3 waypoints (Shift+right-click)
  2. Final waypoint is BUILDING_ENTERABLE (garrison)
  3. Engineer destroys BRIDGE (demo charge)
- Verifies no conflicts between features
- Runs 10 ticks to confirm stability

**TC Coverage**: TC-039 (Advanced command integration)

#### 4. `TestErrorRecoveryJourneyE2E`

**Test**: `test_error_then_save_then_load_recovery`

- Full error recovery workflow:
  1. Game running → AI tick error occurs (monkeypatch)
  2. Error logged → game saves state
  3. Game loads state → AI service restored
  4. Game continues → runs 5 more ticks
- Validates error tolerance and state recovery

**TC Coverage**: TC-040 (Error recovery journey)
