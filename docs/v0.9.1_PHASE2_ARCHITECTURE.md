## 一、Bug 1 修复方案：地图装饰渲染兼容 dict

### 问题分析

**根因**: `decoration_renderer.py:61` 假设 `enhanced_tile` 是对象（有 `.decorations` 属性），但 `GameMap.get_enhanced_tile()` 对 `tiles_enhanced` 字段为 2D list 的地图返回 **dict**。

**代码证据**:
```python
# game_map.py:361-377
def get_enhanced_tile(self, x: int, y: int) -> dict | None:
    if isinstance(self.tiles_enhanced, list):
        # 返回 dict（从 2D array 中取出）
        tile = row[x]
        if isinstance(tile, dict):
            return tile  # ← 返回 dict，不是对象
```

```python
# decoration_renderer.py:61
if not enhanced_tile or not enhanced_tile.decorations:  # ← AttributeError
```

### 架构决策

**方案 A**（推荐）: 修改 `decoration_renderer.py` 兼容 dict
- **优点**: 修改范围小（1 个文件），风险低
- **缺点**: dict 访问语法略繁琐

**方案 B**: 修改 `GameMap.get_enhanced_tile()` 返回对象
- **优点**: 类型一致性好
- **缺点**: 需要定义 `EnhancedTileData` dataclass，影响范围大

**选择**: 方案 A

### 技术方案（方案 A）

```python

# 修改后
```

## 二、Bug 2 修复方案：CombatLog 重新接入

### 问题分析

**现状**: `_archive/combat_log.py` 有 `CombatEvent` 数据结构，但无 UI 面板，未接入 EventBus。

**需求**: 右下角日志面板，显示最近 20 条战斗事件，支持滚动。

### 架构决策

**不复用 archive 代码**（理由：v0.6.x 代码与 v0.9.0 EventBus 不兼容，重新设计更快）

**新设计**:
1. **数据层**: 复用 `_archive/combat_log.py` 的 `CombatEvent` / `CombatEventType` 枚举
2. **订阅层**: 新建 `CombatLogCollector` 订阅 EventBus 事件
3. **UI 层**: 新建 `CombatLogPanel` 渲染日志面板（右下角）

### 组件设计

#### 1. CombatLogCollector（新建）

```python
# src/pycc2/services/combat_log_collector.py

class CombatLogCollector:
    """订阅 EventBus，收集战斗事件到 CombatLog。"""
    
    def __init__(self, event_bus: EventBus, max_events: int = 100):
        self._event_bus = event_bus
        self._events: deque[CombatEvent] = deque(maxlen=max_events)
        self._subscribe_events()
    
    def _subscribe_events(self):
        self._event_bus.subscribe("UnitAttacked", self._on_unit_attacked)
        self._event_bus.subscribe("UnitDestroyed", self._on_unit_destroyed)
        self._event_bus.subscribe("CommandIssued", self._on_command_issued)
        # ... 其他事件
    
    def _on_unit_attacked(self, event_data: dict):
        self._events.append(CombatEvent(
            timestamp=time.time(),
            event_type=CombatEventType.ATTACK,
            source_name=event_data.get("attacker_name"),
            target_name=event_data.get("target_name"),
            damage=event_data.get("damage", 0),
        ))
    
    def get_recent_events(self, count: int = 20) -> list[CombatEvent]:
        return list(self._events)[-count:]
```

#### 2. CombatLogPanel（新建）

```python
# src/pycc2/presentation/ui/combat_log_panel.py

class CombatLogPanel:
    """右下角战斗日志面板。"""
    
    def __init__(self, screen_width: int, screen_height: int):
        self.width = 300
        self.height = 200
        self.x = screen_width - self.width - 10
        self.y = screen_height - self.height - 10
        self._scroll_offset = 0
        self._line_height = 16
        self._visible_lines = self.height // self._line_height
    
    def render(self, screen: pygame.Surface, events: list[CombatEvent]):
        # 绘制半透明背景
        panel_surf = pygame.Surface((self.width, self.height))
        panel_surf.fill((30, 30, 30))
        panel_surf.set_alpha(200)
        screen.blit(panel_surf, (self.x, self.y))
        
        # 绘制日志文本（最多 visible_lines 行）
        visible_events = events[-self._visible_lines - self._scroll_offset:][-self._visible_lines:]
        for i, event in enumerate(visible_events):
            text = event.format_short()
            # 渲染文本（使用小号字体）
    
    def handle_scroll(self, delta: int):
        self._scroll_offset = max(0, self._scroll_offset + delta)
```

## 三、Bug 3 修复方案：音频系统 3 处错误

### Bug 3.1: VoiceCommandSystem API 不匹配

**根因**: 
```python
# voice_command_system.py:56
sound_system.play(f"voice_{cmd_type.name.lower()}")  # 传字符串

# sound_system.py 的 play() 方法期望 SoundType 枚举
def play(self, sound_type: SoundType) -> bool:
    # 访问 sound_type.name 会抛 AttributeError
```

**方案 A**（推荐）: VoiceCommandSystem 构造 SoundType 枚举

```python
# voice_command_system.py:56 修改
from pycc2.domain.value_objects.audio_enums import SoundType

sound_key = f"VOICE_{cmd_type.name}"
if hasattr(SoundType, sound_key):
    sound_system.play(getattr(SoundType, sound_key))
else:
    # fallback: 用字符串尝试（向后兼容）
    sound_system.play(f"voice_{cmd_type.name.lower()}")
```

**方案 B**: SoundSystem.play() 兼容字符串

```python
# sound_system.py play() 方法修改
def play(self, sound_type: SoundType | str) -> bool:
    if isinstance(sound_type, str):
        sound_type = SoundType[sound_type.upper()]  # 字符串转枚举
    # ... 原逻辑
```

**选择**: 方案 B（向后兼容性更好，修改范围更小）

### Bug 3.2: EnvironmentalAudioSystem mono-stereo 不兼容

**根因**: 
```python
# environmental_audio.py:578
raw_audio = generator()  # 返回 1D array (mono)
sound = self._mixer.Sound(array=raw_audio)  # mixer 已初始化为 stereo，抛异常
```

**方案**: mono→stereo 转换

```python
# environmental_audio.py:577 修改
raw_audio = generator()
# 检测 mixer 声道数
if self._mixer.get_num_channels() == 2 and raw_audio.ndim == 1:
    # mono → stereo: 复制到两个声道
    raw_audio = np.column_stack([raw_audio, raw_audio])
sound = self._mixer.Sound(array=raw_audio)
```

**注意**: `pygame.mixer.get_num_channels()` 返回混音器声道数（1=mono, 2=stereo）
