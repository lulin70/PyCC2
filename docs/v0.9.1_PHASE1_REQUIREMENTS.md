## 一、Bug 1: 地图装饰渲染失败

### 症状

9 张地图（arnhem / bridge_assault / night_map / grave / nijmegen / veghel / tutorial / road_ambush / defense_line）渲染时抛 `AttributeError: 'dict' object has no attribute 'decorations'`

### 根因

`decoration_renderer.py:61` 访问 `enhanced_tile.decorations`，但 `GameMap.get_enhanced_tile()` 对含 `tiles_enhanced` 字段的地图返回 **dict** 而非对象。

### 影响范围

- **9/63 张地图**（14%）无法正常渲染
- 含桥梁战役关键地图（arnhem 桥梁是 CC2 核心战役）
- 含夜战地图（night_map 是特殊玩法）
- E2E 测试 2 个 xfail: `test_bridge_map_gameplay` / `test_night_map_gameplay`

### 验收标准

1. 9 张问题地图全部渲染成功（`render_frame()` 返回 True）
2. E2E 测试 2 xfail → pass
3. 全量 63 张地图加载回归测试通过

### PM 优先级评分

⚠️ **10/10** — 破坏性缺陷，阻断 14% 地图可玩性

## 二、Bug 2: CombatLog 模块缺失

### 症状

玩家无法查看战斗事件历史：
- 无法看到伤亡明细（哪个单位被谁击杀）
- 无法看到射击记录（命中/未命中）
- 无法看到命令历史（移动/攻击命令时间线）

CC2 原版有完整的右下角战斗日志面板，是战术复盘的核心工具。

### 根因

v0.6.x ghost 模块清理时，`combat_log.py` 归档到 `_archive/`，未重新接入 EventBus。

**archive 代码现状**:
- `CombatEvent` dataclass（9 种事件类型）
- `format_short()` 格式化方法
- 未完成的 `CombatLogPanel` UI（缺少滚动/渲染逻辑）

### 影响范围

- **100% 战斗场景**无法复盘
- 降低长期留存（玩家无法学习"为什么输了"）
- 新手友好度降低（无战斗反馈）

### 验收标准

1. 右下角战斗日志面板显示最近 20 条事件
2. 支持滚动查看历史（鼠标滚轮/拖动）
3. 事件类型完整：攻击/命中/击杀/未命中/压制/士气/移动/状态/特殊
4. E2E 测试验证日志可见 + 事件累积正确

### PM 优先级评分

⚠️ **9/10** — 核心玩法缺失，严重影响用户体验

## 三、Bug 3: 音频系统 3 处错误

### Bug 3.1: VoiceCommandSystem API 不匹配

**症状**: `voice_command_system.py:56` 调用 `sound_system.play(str)` 时抛 `AttributeError: 'str' object has no attribute 'name'`

**根因**: `VoiceCommandSystem.play_command()` 传递字符串，但 `SoundSystem.play()` 期望 `SoundType` 枚举（访问 `.name` 属性）

**影响**: 语音命令播放失败（"Attack!" / "Move out!" 等单位响应无声）

---

### Bug 3.2: EnvironmentalAudioSystem 立体声不兼容

**症状**: `environmental_audio.py:578` 调用 `mixer.Sound(array=raw_audio)` 时抛 `ValueError: Array must be 2-dimensional`

**根因**: 
- `EnvironmentalSoundGenerator` 生成 **mono (1D)** 数组
- 但 `SoundSystem.initialize()` 已初始化 mixer 为 **stereo (2 channels)**
- `mixer.Sound()` 要求数组维度与 mixer 匹配

**影响**: 环境音（风声/雨声/远处枪声）播放崩溃，GameLoop 用 `contextlib.suppress(Exception)` 隐藏了此 bug

---

### Bug 3.3: Tooltip HIDE_DELAY 死代码

**症状**: `tooltip.py` 的 `HIDE_DELAY=0.1s` 逻辑永远不生效

**根因**: `on_hover()` 的 else 分支（从 unit 切换到 None）走 `unit != target_unit` 立即设 `_visible=False`，HIDE_DELAY 分支不可达

**影响**: 轻微，仅是死代码（不影响功能）

---

### 综合影响范围

- **100% 战斗场景**音效不完整
- 沉浸感归零（CC2 玩家核心诉求是"二战氛围"）
- E2E 测试 `test_audio_e2e.py` 已验证 bug 存在（记录在测试注释）

### 验收标准

1. 修复 Bug 3.1: VoiceCommandSystem 类型转换或 SoundSystem API 兼容
2. 修复 Bug 3.2: EnvironmentalAudioSystem mono→stereo 转换或 mixer 初始化隔离
3. 修复 Bug 3.3: 删除死代码或修正逻辑
4. E2E 测试 `test_audio_e2e.py` 8/8 通过（当前已记录 bug）

### PM 优先级评分

⚠️ **8/10** — 破坏沉浸感，影响核心体验
